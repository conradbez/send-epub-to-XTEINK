1. Typing credentials on e-ink is the worst step in the whole flow. Basic auth means a URL plus a username plus a password on a five-way keyboard. Replace it with a capability URL: https://books.tld/k/<token>/, one string, no password field. Still per-device, still revocable, and it’s over TLS. Tradeoff is the token lands in server/proxy logs — acceptable for a household library, and you can rotate from /devices/. Secondary path: Crosspoint lets you add OPDS servers from the device web UI while in File Transfer mode, ￼ so setup can happen on a PC — but the capability URL makes even that unnecessary.

2. The root feed should be the Inbox. My design makes you open the catalog, then pick Inbox from three nav links. Given there’s no on-device search, every tap saved matters. Point the token URL straight at the inbox feed and demote All Books / Recent to sub-links inside it. Opening the catalog then shows exactly the new books, zero navigation. The firmware no longer auto-appends /opds to your URL, ￼ so you control the entry point exactly.
