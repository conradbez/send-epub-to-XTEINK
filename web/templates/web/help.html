3. On the reader

  1. Settings → System → OPDS Servers → Add
  2. Paste the catalog URL: {{ catalog_url }}
  3. Enter the device username and password from step 2 (Basic auth)
  4. Save, then go Home → OPDS → your library → Inbox
  5. Open a book from the Inbox to download it. Three taps, no cable.

4. Set the download folder (optional)

Firmware 1.5.0 and newer lets you choose where OPDS downloads land and how they are named: Settings → System → OPDS Servers → Download folder. Leave it alone if you are unsure; the default works.

Notes

  • Firmware v1.3.0 or newer is required. Older builds run out of memory during the TLS handshake and simply fail to connect over HTTPS.
  • The Inbox is per device. A book leaves this reader's Inbox once this reader has downloaded it; your other readers still see it. To pull something down again, use All Books.
  • A cancelled download stays in the Inbox. The delivery is recorded only when the last byte arrives.
  • EPUB only. Anything else is rejected at upload — the check reads the file's contents, so renaming a PDF will not sneak it through.
