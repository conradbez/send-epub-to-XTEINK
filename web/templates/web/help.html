Setting up a different reader? Take a new link and paste that one in. The old link stops working the moment you do, so the reader you were using drops off and stops receiving books — this is how you move to a new device, not how you add a second one alongside it. Your whole shelf goes back into the Inbox, so the new reader downloads everything you already had.

2. Paste it into the reader (instructions for the Crosspoint device)

  1. On the reader: Home → File Transfer → Join Network. It shows a QR code and a short address like http://crosspoint.local/.
  2. On your phone: scan the QR (or type that address) to open the reader's own web page.
  3. There: OPDS Servers → Add, paste the link, Save.
  4. Back on the reader: leave File Transfer, then Home → OPDS → your library.

On any other reader, follow its own instructions for adding an OPDS server — the link above is all it needs.

It opens straight on your Inbox — the books you have not downloaded yet.

Notes

  • Firmware v1.3.0 or newer is required. Older builds run out of memory during the TLS handshake and simply fail to connect over HTTPS.
  • The link is the credential. Anyone holding it reads your shelf. It travels in the URL, so it does end up in server logs. Lost the reader or upgraded to a new device? Click “Get a new link” above.
  • EPUB only. Anything else is rejected at upload.
