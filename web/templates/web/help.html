2. Paste it in from your phone

  1. On the reader: Home → File Transfer → Join Network. It is already on your wifi.
  2. The reader shows its own address — http://crosspoint.local/ where that works, an IP address otherwise — and a QR code for it.
  3. On your phone: scan the QR, or type that short address once.
  4. Come back to this tab and tap Copy above.
  5. In the reader's web page: the OPDS Servers card → Add → paste → Save.
  6. Exit File Transfer mode on the reader. Its little web server stops when you leave that screen.

Two tabs in one phone browser, one paste. The reader's keyboard never comes out.

3. Open the catalog

  1. On the reader: Home → OPDS → your library.
  2. It opens straight on the Inbox — exactly the books this reader has not taken yet. No menu to walk.
  3. Open a book to download it. It leaves this reader's Inbox once the last byte lands.

All Books and Recent sit at the bottom of the Inbox, after the books, for when you want something back that this reader already had.

4. If you have no phone to hand

You can still type it: Settings → System → OPDS Servers → Add, then enter the URL from step 1. It is one field — leave username and password empty. The token uses no ambiguous characters, so there is no l-versus-1 to squint at.

Firmware 1.5.0 and newer also lets you choose where downloads land and how they are named, under the same screen. The default is fine.

Notes

  • Firmware v1.3.0 or newer is required. Older builds run out of memory during the TLS handshake and simply fail to connect over HTTPS.
  • The link is the credential. Anyone holding it reads your shelf. It travels in the URL, so it does end up in server logs — that is the price of a setup with nothing to type. Lost a reader? Give it a new link on Devices; the old one dies at once.
  • The Inbox is per device. A book leaves this reader's Inbox once this reader has downloaded it; your other readers still see it. To pull something down again, use All Books.
  • A cancelled download stays in the Inbox. The delivery is recorded only when the last byte arrives.
  • EPUB only. Anything else is rejected at upload — the check reads the file's contents, so renaming a PDF will not sneak it through.
